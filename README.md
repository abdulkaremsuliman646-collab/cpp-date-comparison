# C++ Date Comparison

A C++ console application that compares two dates and determines whether the first date is before, equal to, or after the second date.

## Features

- Compare two dates
- Check if one date is before another
- Check if two dates are equal
- Check if one date is after another
- Read dates from user input
- Use reusable date comparison functions

## Concepts Practiced

- C++ Structures
- Functions
- References
- `const` References
- Conditional Operators
- Boolean Logic
- User Input
- Problem Solving
- Code Organization
